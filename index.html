About the Programme

A group of like-minded math students working on multiple industry oriented, real world problem statements. A sort of online guided workshop on Mathematical Finance and Statistics, Machine Learning, Python, and  Optimization. The Co-Labs initiative is being headed by Sushant Aditya (M.Math, ISI Kolkata), Kunal Rajpoot (M.Math, ISI Kolkata), Vishal Vikram Parth (M.Math, ISI Delhi).We are currently in the first Phase of our 10-13 week plan.

PHASE 1

The first 3 weeks of this program is about building a common base for all the participants in 4 core areas of mathematics and computer science and not focus on any particular problem statements :-

  1. Python
  2. Statistics
  3. Machine Learning
  4. Optimization

As a part of this first phase we sourced out standard reading materials for each of these topics which can be found on the resource page.

For a more detailed overview and the possible structure after phase 1 please refer to PROJECT CO-Labs
